# Screenshot Audit Rubric

Inspect every proof screenshot with these checks:

## Composition

- No duplicate status or combat surfaces
- No overlay collision
- No clipped or unreachable controls

## Readability

- Labels readable against the terrain
- Outline or contrast visible on actor names
- No text stacked over other text

## Honesty

- Every visible action appears meaningful
- No placeholder or debug text in the main player path
- Shown state matches the gameplay moment

## Entity clarity

- Player is clearly distinguishable
- NPCs, threats, and animals are visually different
- Movement does not look like teleportation or glow artifacts

## Required captures

- title
- creation flow
- exploration shell
- dialog
- travel
- combat
- save/load
- continue
