# Vertical Closure Checklist

Use this before calling dialog, travel, or combat complete.

## Dialog

- Click-to-approach works
- Talk opens one readable dialog surface
- Numbered options are visible
- Skill checks are visible and truthful
- Close and escape behavior are deterministic
- Manual and semantic desktop proof exist

## Travel

- Reachable destinations are clear
- Travel interaction produces feedback
- Arrival changes visible location state
- Save/load preserves travelled state
- Manual and semantic desktop proof exist

## Combat

- Exactly one combat surface is active
- Turn ownership is readable
- Action availability is truthful
- Feedback is visible
- Exit back to exploration is clean
- Manual and semantic desktop proof exist
